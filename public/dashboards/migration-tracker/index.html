How to read the cards

Built from the pipeline's own stage definitions. The colour down the left of each card is its stage, using the same colours as the progress bar. The first pill is what the pipeline is doing with the model right now. The other pills are checks.

✓ Structural pass every table, column and measure matches the production model.
✕ Structural FAIL something in the model's structure differs from production.
Parity preview 16/24 tables whose values match production in a preview run. A preview is a guide only, because the data cut-offs differ.
READY OBJECTS EXIST objects missing whether the Snowflake objects the model needs exist.
Snowflake tables are empty dashed pills flag a blocker to look at.
